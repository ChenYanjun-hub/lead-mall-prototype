这份交付是怎么来的

周二拿到题，并未着急就开始做原型——先把业务弄明白：头等仓在工业与物流地产里靠什么赚钱；线索商城从平台自行获客、客服电话核实录音、上架为商品、到业主与经纪人用积分认领的闭环怎么转；付费的是谁、被交易的是谁；平台的收入函数里有没有"成交"这个变量。随后以经纪人身份把小程序的功能完整体验了一遍，记录卡点。原型是在这之后才开始画的。

核心判断，一句话

平台已经解决了"信任"——电话核实、通话逐字稿凭证、无效退积分，这套机制在行业内领先。但它没有解决"分辨"：定价按客户规模分三档，而成交收佣同样是面积的线性函数，两个价格用的是同一个维度，成交概率在整个定价模型里被当成了常数。所以本次改版的目标不是拉高认领率，而是提升每积分的成交转化率。

我的取舍
  • 小程序功能已完整体验，本次只动线索商城。租控表是成熟的现有功能，不在漏斗主路径上。
  • 用户量与线索认领率无任何公开披露，全网检索已确认。相关推导改用汽车行业公开基准外推，交付中出现的任何精确数字都应视为待内部数据校准的占位值。
  • 用户分层来自产品完整体验与公开信息的推断，未做用户访谈。下一步会先找 5–8 位独立经纪人验证两件事：一次失败认领后的真实流失阈值，以及他们判断线索好坏时实际在看哪些字段。
  • 质量分的五维权重是拍的，需要用内部退单率数据做回归才能定。
  • 原型优先保证漏斗主链路（列表 → 详情 → 认领 → 跟进 → 退单）可真实运行，次要页面为示意。

先说清楚：谁在买，谁在卖，卖的是什么

一条"线索"，指的是一家正在找仓库的企业的真实租赁需求，以及它的联系方式。 产品自己的措辞已经说明了商品是什么——列表页写的是"上海共 408 个客户"， 首页写"3800 个新客户急租厂房仓库"，登录条写"首次登录送 1 个免费客户"。 需求描述只是让人判断值不值得买的说明书，真正付钱买到的是那串手机号。

三个角色

注意这里的不对称：真正被交易的那一方，并不是这个市场的用户。

租户企业

线索的来源

电商、物流、制造、零售连锁，也包括截图里那位做可回收物中转的小老板。

他们免费提交需求，既不发布也不购买线索——他们是被交易的那一方，甚至不知道自己被上架了。

业主

付费方

园区招商、厂房产权方、二房东。有空置仓要出租。

通过首页"免费挂牌"把房源放进平台库，再来商城买正在找仓的客户。

经纪人

主力付费方

工业地产中介，手上代理一批仓源，靠成交佣金吃饭。

头部物流地产商有自营招商团队，不会一条条买线索。实际高频消费的是中小经纪人与二房东。

线索由平台自己生产，不是用户发布的

证据在通话逐字稿里：那段对话是平台的人在问客户——"你这边是找厂房是吗""要多大面积""也是你们公司自己用吗""那你留一个联系微信电话吧"。这是需求核实回访，不是租户在填表。详情页底部标注的"平台每日获客 3,000 组"，说的就是这条产线的产能。

所以完整链路是：平台通过找仓入口、搜索广告、来电等渠道捕获需求 → 客服电话回访核实并录音 → 整理成结构化需求上架并标价 → 业主或经纪人付积分认领 → 拿到手机号自行推进。

为什么这门生意成立

物流地产与住宅有一个根本区别：仓源不稀缺，需求才稀缺。

头等仓的双边结构

首页那两张卡片已经把商业模式说完了。

免费侧 · 留住供给
  • 租控表：一张表管完所有房源，免费工具，作用是留住经纪人与业主、同时采集仓源数据
  • 免费挂牌：把空置房源收进平台库，既是获客钩子也是供给资产
  • 这两块本身不赚钱，是漏斗前端
收费侧 · 变现终端
  • 线索商城：按积分出售客户联系方式，平台唯一的直接收入来源
  • 定价已分三档：普通客户 50 / 大客户 100 / 超大客户 200 积分每条，分档依据是客户规模
  • 积分通过充值获得（首充 ¥99 得 500 分，¥500 档赠 10%），也可通过上传成交换取 200–500 积分
  • 平台不参与成交佣金分成——"成交收佣"是给经纪人看的预期收益，不是平台的分成
这个结构带来的两个张力

其一，租户是被交易方，不是用户。租户免费提了一次需求，联系方式被按积分卖给多位经纪人，其体验是"提了一次需求，被十个中介轮流打电话"。这会反过来污染线索池——客户被打烦了就不接电话，经纪人认领后打不通，退单率上升。限制认领席位不只是保护经纪人的独占性，也是保护线索源头本身的质量。

其二，平台不抽佣是长期的战略缺口。卖出线索即收钱、成交与否与平台无关，这正是房产端口费模式的病根。若未来能引入成交分佣，平台收入才会与线索质量真正绑定。这需要交易闭环能力（跟进状态、合同、资金），不是短期可落地的，但它决定了这个产品长期能不能摆脱"卖曝光"的宿命。

这决定了改版的三个前提

商品是"人"，不是"信息"

推论
质量的定义不是"描述写得详不详细"，而是这个人是不是真的、找不找得到、需求能不能接住。质量分模型必须围绕这三件事设计，而非围绕字段填充率。

线索不可再生，超卖即透支

推论
仓储需求总量本就稀缺，一家企业找到仓就离开市场。拉高认领率的最快方式是超卖和降价，而这恰恰是最快的自杀方式。目标必须是每积分的成交转化率。

平台两头的数据都在手上

推论
租控表与免费挂牌握着供给侧仓源，线索商城握着需求侧需求，这是通用信息平台不具备的资产。把两者接起来做匹配度，是本次改版中最难被同行复制的一环。

线索商城的用户是谁，以及谁最容易被这个模式伤害

付费认领意味着每一次点击"认领"都是一笔赌博性投资。 所以用户定位的核心问题不是"谁会用"，而是—— 按当前定价，这条线索对哪一类用户的 ROI 为正？ 答案并不是所有人。

四类用户对"合适的线索"定义完全不同

这正是统一的商城列表天然低效的原因——408 张同样的卡片，同时服务着四种互不相容的诉求。

他们真正雇佣线索商城做的事

不是"看到线索"，而是以可控的成本，拿到一个能签约的租户。 所以线索的价值由三个因子相乘决定，任何一项为零，整条线索即归零：

可转化性
  • 客户是真的、需求是真的、条件我能接住
  • 对应改动：质量分、通话摘要、仓源匹配度
独占性
  • 不是第十个打给客户的人
  • 对应改动：认领席位上限
及时性
  • 客户还没被别人签走
  • 对应改动：时效衰减定价、订阅推送
定位的核心矛盾

平台卖线索，卖得越多越赚钱；但同一条线索被越多人认领，每个经纪人的 ROI 就越低，下一次就不买了。 所以真正的战略问题是——线索商城要做"线索批发市场"，还是"精准匹配的准会员制"？

本方案选择后者，理由是行业特性：仓储需求总量本就稀缺，一家企业找到仓就永久离开市场。 走批发路线是杀鸡取卵，而这个鸡的存量很小。所有的改动——分级定价、席位上限、匹配度、时效衰减——都是同一个选择的展开。

当前模式伤害最深的，恰恰是主力人群

独立经纪人付 10 积分认领一条线索，可能三个月后才知道这单黄了。 仓储成交周期长达 3–6 个月、转化率本就低，而平台目前不提供任何归因手段—— 没有跟进记录、没有质量分、没有同类成交率参考。

结果是：用户无法区分"我运气不好"和"这条线索本来就是废的"， 于是把所有失败都归因于平台，得出"这平台骗钱"的结论。 这不是信任机制不够，而是缺乏归因能力——用户没有办法验证平台的承诺是否兑现。 本方案中的质量分、同类成交率、战报回填，本质上都是在给用户提供归因工具。

需要向内部确认的定位问题

如果头等仓有自营经纪团队，那么好线索是先给自营，还是先进商城？ 外部经纪人一旦怀疑"商城里的都是自营挑剩下的"，信任问题就不在产品层面，认领率的天花板会被锁死。

另一个是供给密度的城市差异：上海 408 条、南京 190 条、苏州更少。 同一套产品在供给稀薄的城市，用户体验是"翻两页就没了"， 分级定价与席位上限在低密度城市可能需要不同参数。

外部数据校准：查得到什么，查不到什么

以下为全网公开检索结果。先说结论：头等仓的注册用户数、活跃经纪人数、线索认领率、退单率，均无任何公开披露。 这不是检索不力，而是这类平台侧漏斗指标本就不对外公布。因此本方案的用户量与认领率判断， 走的是"平台侧用可查的结构性事实定性，漏斗侧用同构行业的公开基准定量"这条路径—— 任何以精确数字出现的认领率都应被视为待内部校准的占位值。

同构行业的线索漏斗基准

选汽车经销商线索作为参照系，是因为它与仓储线索结构同构：高客单价、长决策周期、线上获客线下成交、 平台按线索收费而不参与成交分成。它比仓储行业早走了十年，且已经走到了坏结局——这正是它的参考价值。

这组数字为什么是本方案最重要的外部证据

汽车行业的困局不是"线索太贵"，而是线索的挂牌价与它的成交概率脱钩： 平台按曝光和数量收费，质量差异不进入价格，于是劣质线索的边际成本为零，供给端持续注水， 转化率从 5% 一路掉到 1.5%，最终把单条成交成本推到 1,580 元。买方付的钱没变，买到的东西变差了。

头等仓现在正处在这条曲线的起点，而不是终点。 平台已经用电话核实与通话凭证解决了"线索是不是真的"，这一步领先同行； 但定价仍然只按客户规模分档——成交概率在定价模型里被当成了常数，与汽车行业犯的是同一个错误。 这也是本方案坚持"不把认领率作为北极星"的原因：认领率正是那条先涨后崩的曲线。

改版前后对比与指标预期

本次改版不新增任何一个流量入口，也不改变商业模式， 全部改动集中在让用户能够分辨线索质量，以及让平台能够回收成交结果这两件事上。

现状
  • 定价按客户规模分三档，但规模与收佣是同一维度，成交概率不进入任何公式
  • 成交收佣 = 面积 × 39.36，与区位、质量、成交率无关
  • 核验状态、通话凭证、紧急度全部藏在详情页
  • 通话逐字稿 2,140 字无摘要，最强信任资产被埋没
  • "特殊要求"六个字段几乎全为"暂无信息"，而答案就在同页通话记录里
  • 降价包装为"限时特惠"，教会用户等待
  • 无新手引导，积分与退单规则需付费后才能理解
  • 认领人数无上限，租户可能被十个中介轮流联系
  • 回填只收成交这一个正样本，且需 3–6 个月才反馈；"联系不上"等负信号留在 CRM 未回流
  • 订阅只能按行政区，无法按仓源特征；已有的仓源数据未用于线索匹配
改版后
  • 在现有规模档之上叠加质量系数（A ×1.3 / B ×1.0 / C ×0.6），补上缺失的维度
  • 预估收佣纳入区域均价与历史成交率，折算每积分期望收益
  • 五类信任标识前置到列表卡片首屏
  • AI 提炼六维通话摘要，逐字稿折叠保留可验证性
  • 结构化抽取回填字段并标注来源，缺失项转为沟通清单
  • 改为时效衰减明示，用户理解规则后倾向尽早决策
  • 三步引导覆盖选择、支付、兜底，终点发放 0 元试领
  • 限 3 人认领并明示剩余席位，同时保护独占性与租户体验
  • 补齐轻量四档回填含战败负样本，并把 CRM 已有的负信号接回评分
  • 仓源匹配度进入全链路，订阅升级为按我的仓源特征匹配推送

关于"认领率"这个指标本身

需要明确一个判断：认领率不应作为北极星指标。 在付费线索模式下，认领率可以通过降价、增加曝光、弱化风险提示轻易拉高， 但如果成交转化率不同步提升，结果是用户 ROI 下降、退单上升、复购停止。 房产行业已经完整走过这条路径——端口费模式下平台收入与线索转化解耦， 平台不为结果负责，最终演变为虚假房源泛滥与经纪人集体抵制。

建议的指标结构：以 每积分成交转化率 为北极星， 认领率与消化率作为过程指标，退单率与复购率作为健康度指标。 三者背离时（认领率涨、退单率同步涨），说明产品正在透支信任。

长期方向：从卖线索到分佣金

本次改版全部在现有商业模式内完成。但需要指出一个更根本的结构问题： 平台卖出线索即收钱，成交与否与其收入无关。 "成交收佣 ¥3,936"是经纪人的预期收益，平台不参与分成。 这意味着平台的收入函数里没有"成交"这个变量——这正是房产端口费模式最终失控的机制根源。

分级定价是在现有模式内能做到的最强对齐：让平台的收入与线索质量正相关。 而真正的解法是引入成交分佣，让平台收入与经纪人的成交直接绑定。 这需要交易闭环能力——跟进状态、合同、资金流转，短期无法落地。 但本方案中的战报回填正是通往那一步的第一块基础设施： 先把成交数据收回来，才谈得上按成交收费。

怎么落地：优先级、指标、算法与实验

前面六屏回答了"改什么"，这一屏回答"先做哪个、怎么衡量、怎么验证"。 有一条依赖关系决定了整个排期顺序：质量分模型需要结果数据来训练。 平台已经用"上传成交 +200～500 积分"重金收集正样本，但负样本（联系不上、战败） 仍散落在 CRM 里没有回流。所以第一期最该做的不是新功能， 而是把已有的负信号接回评分体系——这是全案中成本最低、杠杆最大的一步。

质量分冷启动：先用规则版，别等模型

在成交数据积累到位之前，用可解释的加权规则打分。权重需与运营共同校准，以下为建议初值。

维度权重取值规则
需求信息完整度30%面积、区位、用途、租期、预算、启用时间六项的填充率
核验等级25%已电话核实且有录音 = 100；已核实无录音 = 60；未核实 = 0
需求紧迫度20%明确"随时启用" = 100；一个月内 = 70；未提及 = 30
客户身份15%公司自用且非中介 = 100；身份未知 = 40；识别为中介 = 0
描述丰富度10%通话时长与抽取出的有效条件数量

分级：A ≥ 85 分 / B 60–84 分 / C < 60 分。 定价不推翻现有的规模三档（普通 50 / 大客户 100 / 超大 200），而是在其上叠加质量系数： A 级 ×1.3、B 级 ×1.0、C 级 ×0.6。例如同为普通客户档，三条线索分别定价 65 / 50 / 30 积分。 切换到模型版的条件：每个等级累计 300 条以上带成交结果的回填样本后， 改用预测成交概率的模型输出分数，规则版转为兜底与冷启动。

实验设计

分流方式
  • 必须按用户 ID 分流，不能按线索分流
  • 按线索切会导致同一条线索在两组显示不同价格，用户之间互相截图对比即穿帮
  • 且线索池共享，实验组抢走的线索对照组就看不到了——这是双边市场 AB 的经典污染
节奏与周期
  • 先灰度 10% 用户观察 3 天，无异常再放量至 50/50
  • 至少运行 4 周
  • 成交类指标短期看不到——仓储成交周期 3–6 个月，主指标只能看认领转化率与退单率，成交指标做长期跟踪
护栏与停止条件
  • 退单率相对上升超过 20% 即回滚
  • 租户接通率下降、客诉工单量上升即回滚
  • 回填率低于 40% 时暂停下游指标解读

定价空间：与汽车行业的横向校准

按充值页折算积分价值：首充 ¥99 得 500 积分（约 ¥0.20/分，属获客补贴价）； ¥500 档赠 10%，约 ¥0.91/分，可视为常态成本。据此换算单条线索的实际售价：

档位积分折合人民币参照
普通客户50约 ¥45汽车垂媒线索采买成本 200–500 元/条；按 2024 年行业数据，折算到单条成交线索已达 1,580 元
大客户100约 ¥91
超大客户200约 ¥182

仓储单笔佣金（¥3,936 至 ¥11,808）远高于单车利润，而线索定价却低于汽车行业。 这说明问题不是价格太高，而是质量不可辨——用户不敢为不确定的东西付更多钱。 一旦质量可辨，A 级线索存在明确的提价空间，这也是分级定价能够跑通的前提。

这套方案最大的落地风险

分级定价会短期扰动收入结构。C 级线索降价 40%，而 A 级提价 30% 能否覆盖，取决于线索池的等级分布——如果池子里大部分是 B、C 级，总收入会下滑。

应对方式是分两步：先只上质量分展示、不动价格，观察各等级的认领率与退单率差异，用真实数据校准系数，再上分级定价。这样既降低收入风险，也让定价有依据而非拍脑袋。

上表的横向校准正是这一步的底气所在：价格带向上是有空间的，只是这个空间必须先用质量证明来换取。
